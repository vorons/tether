# Спека: UX/UI апгрейд TUI (M8)

date: 2026-09-17 · milestone: M8 (см. docs/ROADMAP.md)
spec-base: docs/staging/specs/2026-09-17-finish-agent.md (M7, закрыт)

## Контекст

TUI работоспособен (M7), но визуально и эргономически сырой: markdown не
рендерится, глифы ломают ASCII-режим, часть ключей конфига мёртвая, мышь
крадёт нативное выделение. Пользователь утвердил все 4 группы улучшений:
долги + quick wins, markdown-lite, навигация + статус, мышь + scrollback.

## Контракт

```
contract:  TUI рендерит ответы агента как markdown-lite (код-блоки в рамке,
           инлайн-код, списки); ASCII-режим заменяет глифы; все ключи
           cfg.ui действуют; цифры/стрелки/буквы в подтверждении; токен-бар
           с цветовыми порогами; Ctrl+F поиск; мышь опциональна, нативное
           выделение доступно всегда.
invariant: transcript_cache инвалидация при любом изменении рендера;
           ASCII-режим не эмитит ни одного байта >0x7F;
           mouse не включается при ui.mouse == "off";
           существующие биндинги M7 не ломаются (Ctrl+C/Q/J/T/O/R/N, /команды).
test:      make test + новые юнит-тесты (markdown, ascii-маппинг, поиск-модель,
           digit-map); TUI-поведение — ручная приёмка.
```

## Решения

### R1. ASCII-режим докрутить до обещанного (долг)

- Таблица маппинга глиф→ASCII на этапе рендера: `●`→`*`, `⚙`→`[t]`,
  `›`→`>`, `✗`→`x`, `✻`→`*`, `⠋⠙⠹…`→`|/-\` (спиннер: ASCII-набор),
  `┌┐└┘─│`→`+-+|` (рамки), `↻⏹↔↓`→`[r] [x] < > v`, `⚠`→`!`, `─⇔`→`-`.
- Реализация: одна функция `ui.to_ascii(s)` + локальная обёртка `A(s)` для
  строк-литералов в render-функциях; `_ascii` уже есть.
- test: юнит — to_ascii не содержит байтов >0x7F на наборе всех глифов;
  спиннер в ASCII-режиме из `|/-\`.

### R2. Мёртвые ключи конфига оживить (долг)

- `ui.theme = "default" | "mono" | "solarized"` — таблица тем
  (`theme[role] = "36;1"`), роль→sgr-код; `mono` = без цветов вообще.
  Это фундамент: все `cyan()/yellow()/...` переходят на роли.
- `ui.wrap = false` — отключает перенос строк транскрипта (обрезка до ширины).
- `ui.mouse_selection = true` — см. R8 (passthrough).
- Неизвестные роли тем → fallback на default; битые значения — дефолт + warning
  в debug-лог.

### R3. Quick wins ввода/меню (утверждено)

- Подтверждение: клавиши `1..6` выбирают опцию (как y/a/A/d/n/Esc).
- Спиннер с секундами: `⠙ tether думает… 12s` (elapsed с начала busy).
- Pending-инструмент показывает elapsed: `⚙ read  … 0.8s`.
- Jump-to-bottom: `End`/`G` (когда input пуст) → `S.scroll = 0`,
  `user_scrolled = false`.
- Индикатор скролла в статусе: при `user_scrolled` — `⏸ +N` (N = строк ниже
  последней видимой), иначе — ничего (чисто).
- Ошибка → оверлей: `Enter` при активном баннере открывает overlay `error`
  с полным текстом; `Esc` закрывает.

### R4. Markdown-lite рендер (главный визуальный апгрейд)

Грамматика (только это, без таблиц/ссылок/HTML):

- Код-блок ` ```lang ... ``` ` → рамка `┌─ lang ─┐ … └──────┘`, без wrap
  (обрезка + индикатор `→` на усечённых строках), строки не красятся.
- Инлайн-код `` `x` `` → окрашенный (accent-роль) фрагмент.
- `**bold**` → bold-роль; `*italic*`/`_italic_` → italic (без вложенности).
- Заголовки `# `..`### ` → bold + underline-пустая строка после.
- Списки `- `/`* `/`1. ` → `• ` (ASCII: `- `), отступ 2.
- Экранирование: `\``` и `\*` не рендерятся как разметка.

Архитектура: `ui.md` — чистая функция `md.render_entry(text, width, theme) →
lines[]`, вызывается из `render_entry` для `role=="assistant"`; результат
кэшируется в transcript_cache как раньше. Парсер — построчный, без регэкспов
с бэктрекингом (учитывать урок ADR-2026-09-17-lua-json-parser).

test: юниты на md-функцию: код-блок с lang, инлайн-код рядом с `*`,
заголовок, список, экранирование, wide-unicode внутри (width по ulen),
ASCII-режим (`→`→`>`, `•`→`-`).

### R5. Токен-бар в статусе

- `▓▓▓░░░░ 42%` (10 ячеек), цвет: зелёный <70%, жёлтый ≥70% (порог
  summarize_at), красный ≥90%; в ASCII: `[###-------] 42%`.
- Проценты от `tokens_max`; при `tokens_estimated` сохранить префикс `≈`.

### R6. Поиск по транскрипту (Ctrl+F)

- Модель: `S.search = { query, matches[], idx }`; вход — оверлей-подсказка
  (строка поиска в hint-зоне, не отдельный overlay-экран).
- Матч — подстрока (case-insensitive) по отрендеренным display_lines;
  переход `n`/`N` (и F3/Shift+F3): прокрутка так, чтобы матч был виден.
- Реализация прокрутки: display_lines уже даёт полный список; найти индекс
  строки матча → вычислить scroll offset (матч в нижней трети экрана).
- Подсветка матчей: inverse-video на строке матча при рендере (только
  активный матч — упрощение, зафиксировано).
- Esc/Ctrl+F повторно — выход из поиска.

test: юнит модели поиска (массив строк → индексы матчей) и расчёта
scroll-оффсета; TUI-обвязка — ручная.

### R7. Токен-подсветка и hint не дублируются

- hint-строки для search-режима и confirmation уже различны — обновить тексты
  (поиск: `Esc отмена · n/N следующий/предыдущий`).

### R8. Мышь: вернуть выделение терминала (главная боль)

- **Решение**: `cfg.ui.mouse = "auto"|"off"|"on"|"selection"`.
  - `auto` (новый дефолт): мышь ВКЛ только когда есть интерактивные цели
    (confirmation меню, палитра) и ВЫКЛ в остальное время → нативное
    выделение работает по умолчанию.
  - `off`: никогда.
  - `on`: всегда (как сейчас, для тех, кому мышь нужна постоянно).
  - `selection`: эквивалент off + drag-select вручную копирует в OSC 52.
- Escape-последовательности `?1000h/?1006h` эмитить/снимать динамически при
  смене busy/confirmation/palette состояний (не на каждый кадр — только при
  переходе состояния).
- Shift+drag при включённой мыши — терминал сам отдаёт выделение (не наш код),
  упомянуть в help-оверлее.

test: юнит — таблица состояний (busy, confirmation, palette) × режим →
ожидаемое `?1000h/`нет; переключение эмитится ровно при смене состояния.

### R9. Alt-screen опция (scrollback)

- `cfg.ui.alt_screen = false` (новый дефолт false — нативный scrollback
  терминала сохраняет историю; текущее поведение — repaint на месте).
- При `true`: `?1049h` на старте, `?1049l` на выходе (сейчас не используется).
- Совместимость: atexit/restore_termios в C уже чистит экран; проверить
  порядок эмитов, чтобы не оставлять терминал в alt-screen после exit.

## Обнаружено в ходе работ (послеутверждённые находки)

- **E1 (критично, найден при приёмке R9):** `config.load` молча игнорировал
  пользовательский конфиг — `loadfile` возвращает `(chunk)` на успехе, а код
  читал `local ok, chunk = loadfile(...)`, где `ok=function, chunk=nil`.
  Все ключи (theme/wrap/mouse/alt_screen/model) не применялись никогда.
  Фикс: `local chunk = loadfile(...)`, ручная верификация alt_screen=true.
- **E2:** `utf8.sub` не существует в стандартном Lua 5.4 — `usub` в ui.lua
  заменён на реализацию через `utf8.offset`.
- **E3:** F3/Shift+F3 — xterm шлёт `CSI 13~`/`CSI 14~`; добавлены в read_key.
- **E4 (после-коммитный аудит):** мёртвые ключи `cfg.ui` оживлены:
  `ui.ascii` ("auto"|"on"|"off" — override env-детекта), `ui.thinking`
  ("collapsed" скрывает thinking на старте, Ctrl+T переключает),
  `ui.collapse.{read,list,grep}` (порог обрезки тела tool-блока, было
  хардкод 200), `ui.keyboard_protocol` ("auto"|"kitty"|"modifyOtherKeys"|
  "plain" — override C-детекта). Мёртвый `ui.mouse_selection` удалён
  из default_config (заменён на `ui.mouse`, R8). Seams: `M.ascii_active`,
  `M.initial_thinking_visible`, `M.tool_collapse_cap`,
  `M.kb_protocol_from_config` (T38, 242/242).

## M9 — упрощение UI (запрос пользователя, 2026-09-17)

Прямые запросы на удаление/изменение, все подтверждены тестами T39 (243/243):

- **Поиск удалён полностью**: Ctrl+F-режим, n/N, F3/Shift+F3, hint,
  подсветка матча, `M.search_matches`/`M.search_scroll_for`. Причина: не нужен;
  к тому же навигация n/N внутри search-режима конфликтовала с вводом текста.
- **Токен-бар → текст**: вместо `▓▓░░ 42%` — просто цветной `42%`.
  Цвета порогов сохранены: зелёный <summarize_at, жёлтый >=summarize_at,
  красный >=90%. `M.token_bar` заменён на `M.token_pct`.
- **Hint-строка удалена**: её строка отдана транскрипту. Спиннер с
  секундами остался в статус-строке во время busy.
- **Команды `/help`, `/status`, `/log` и их оверлеи удалены** вместе с
  `?`-биндингом. Оставшиеся: `/clear /compact /model /resume /new /quit`.
  Неизвестная команда — предупреждение в транскрипте (прежнее поведение).
- **Палитра без рамки**: вместо `┌─┐ └─┘` и reverse-video выбранный пункт
  выделяется accent-ролью темы, остальные — dim.
- **Скролл-артефакты исправлены**: (а) `vlen()` — ширина строки без ANSI
  SGR-последовательностей; pad/trunc в статус-строке считали escape-байты
  как видимые символы; (б) `trunc()` обрезает по ширине терминальных колонок,
  сохраняя целые UTF-8-кодовые точки и ANSI-последовательности;
  учитывает широкие и комбинируемые символы, завершает обрезанный текст сбросом SGR; (в) при изменении
  viewport (top) все видимые строки транскрипта принудительно
  перерисовываются — row-diff больше не сравнивает со строками предыдущего
  окна.

## Out of scope

- Подсветка синтаксиса в код-блоках (после обкатки markdown-lite).
- Drag-select мышью внутри TUI (сложно; R8 auto решает боль).
- Темы целиком за пределами 3 вариантов; images/HTML.

## Working notes

- render_entry — единственная точка рендера записей; md-функция встраивается
  туда без изменения transcript_cache-механики.
- Спиннер-кадры уже таблица SPINNER — добавить ASCII-вариант рядом.
- mouse-эвенты при выключенной мыши просто не приходят — код T17 остаётся.
- Порог цвета токен-бара привязать к cfg.context.summarize_at (не хардкод 70).
