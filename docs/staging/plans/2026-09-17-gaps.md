# tether — gap plan (audit 2026-09-17)

spec: docs/design.md
date: 2026-09-17

## Goal
Close all 20 gaps found in audit: wire confirmation into UI, fix broken
JSON parsing, implement missing design features (/model, mouse, clipboard,
keyboard protocol, retries, summarization, ASCII mode, print mode, log).

## Grouping

- **P0 correctness** — bugs that make shipped features not work: K2, K3, K4, K6, K5
- **P1 design features, small** — individually short, no shared contracts: K1, K7, K8, K10, K17, K18, K19
- **P2 design features, larger** — need new C-host APIs or multi-module wiring: K9, K11, K12, K13, K14, K15, K16, K20, K21

## Tasks

- [x] T1: Fix `session.lua: list_session_files` gmatch `[^]` → `[^\n]+`
  - files: src/tether/session.lua
  - acceptance: `lua -e "..."` or unit test: `session.session_files(ws)` returns non-empty list for a workspace with saved sessions

- [x] T2: Fix `agent.lua: parse_args` — replace regex-only parser with a
  minimal JSON parser (reuse `api.lua: json_decode` via `load`, handle
  nested objects/arrays/numbers/bools)
  - files: src/tether/agent.lua, src/tether/api.lua
  - acceptance: `parse_args('{"path":"a","offset":3,"limit":null}')` returns
    `{path="a", offset=3, limit=nil}`; test in `tests/lua_tests.lua`

- [x] T3: Fix `agent.lua: should_confirm` — correct workspace boundary check
  (`resolved:sub(1, #WS) == WS` instead of `rel ~= path`)
  - files: src/tether/agent.lua
  - acceptance: write tool to `./file.lua` → no confirm; write to `/etc/x` → confirm

- [x] T4: Wire confirmation into UI: handle `confirmation` event in
  `handle_agent_event`, set `S.confirmation`, call `agent.confirm()` on keypress
  - files: src/tether/ui.lua, src/tether/agent.lua
  - acceptance: `make test` green; manual: write outside workspace shows menu, `y`/`n` work

- [x] T5: Fix M6 single binary — add `luasystem` to Makefile (or drop it),
  ensure all `.lua` modules are in `embed.c`
  - files: Makefile, src/host/main.c
  - acceptance: `make && ./tether --version` → `tether 0.1.0`, no external
    Lua install needed; binary runs standalone

- [x] T6: Implement `/model` command — call `api.list_models()`, show palette,
  update `S.model_name` and persist in session
  - files: src/tether/ui.lua, src/tether/api.lua
  - acceptance: type `/model` → list appears, select one, model changes in status line

- [x] T7: Implement `api.list_models()` via `GET {base_url}/models` (curl pipe)
  - files: src/tether/api.lua
  - acceptance: returns list of model names from API; test with mock

- [x] T8: Implement double Ctrl+C (< 1s) → quit; single Ctrl+C during stream
  → abort, keep text
  - files: src/tether/ui.lua
  - acceptance: manual check per §6.6

- [x] T9: Token estimation `ceil(chars/4)` when no `usage` from API;
  prefix `≈` in status line
  - files: src/tether/ui.lua
  - acceptance: after sending a message, status shows `≈1.2k/32.0k` or similar

- [x] T10: Read `system_prompt` from config in `agent.lua`
  - files: src/tether/agent.lua, src/tether/config.lua
  - acceptance: `config.system_prompt = "my prompt"` → agent uses it; string or file path

- [x] T11: Implement `--debug` log to `~/.tether/log/tether.log`;
  `/log` overlay reads last 200 lines
  - files: src/tether/app.lua, src/tether/ui.lua
  - acceptance: `./tether --debug` creates log file; `/log` shows its tail

- [x] T12: Read `ui.collapse` thresholds from config in UI tool rendering
  - files: src/tether/ui.lua, src/tether/config.lua
  - acceptance: `ui.collapse = {read = 20}` → read tool blocks cap at 20 lines

- [x] T13: Bracketed paste (`ESC [ 200 ~ ... ESC [ 201 ~`)
  - files: src/host/main.c, src/tether/ui.lua
  - acceptance: paste multi-line text via terminal → all lines in input buffer

- [x] T14: Context summarization at `summarize_at` (default 0.7)
  - files: src/tether/agent.lua
  - acceptance: when tokens_used > 0.7 * tokens_max, agent calls model to
    summarize old messages, inserts `── summary ──`, continues

- [ ] T15: API retries: 429/5xx, exponential backoff 0.5/1/2s, respect Retry-After
  - files: src/tether/api.lua
  - acceptance: mock server returning 429 → 2 retries → succeeds; test in lua_tests

- [ ] T16: Keyboard protocol detection (kitty → modifyOtherKeys → Ctrl+J fallback),
  status line shows `⌨ kitty` etc.
  - files: src/host/main.c, src/tether/ui.lua
  - acceptance: in kitty terminal, Shift+Enter works; in xterm, Ctrl+J works

- [ ] T17: Mouse: SGR scroll → transcript scroll; click on confirmation/palette items
  - files: src/host/main.c, src/tether/ui.lua
  - acceptance: scroll wheel scrolls transcript; click on palette item executes it

- [x] T18: OSC 52 clipboard: copy last assistant response with Ctrl+Shift+C;
  fallback pbcopy/xclip/wl-copy
  - files: src/host/main.c, src/tether/ui.lua
  - acceptance: in terminal supporting OSC 52, Ctrl+Shift+C copies last response

- [x] T19: `--print "prompt"` mode: non-interactive, stdout = final text,
  stderr = trace, exit 0/1, no confirmation allowed
  - files: src/tether/app.lua
  - acceptance: `./tether -p "hello"` runs one agent turn, prints text to stdout, exit 0

- [x] T20: ASCII mode: `TERM=dumb` or `NO_COLOR=1` → ASCII glyphs, no color
  - files: src/tether/ui.lua
  - acceptance: `NO_COLOR=1 ./tether` → `>` instead of `›`, no ANSI codes

- [ ] T21: `make test` all green (luac + unit + host smoke)
