# tools/embed_order.txt — the single source of truth for Lua module embedding.
#
# Two orders (they differ on purpose):
#   [embed]  byte layout in src/host/embed.c (embed.lua argument order).
#   [load]   main.c mods[] load order (globals must precede their readers).
#
# Line format in [embed]:  <varname> <path>   (varname becomes <varname>_lua)
# [embed] also drives LUA_MODS (prerequisite lists are order-insensitive,
# so its order is normalized to embed order — historically it differed).
# In [load]:               <varname>          (path/comment reuse the [embed] entry,
#                           but ordering comments use `##` lines, emitted as /* */).
# One `#` starts a file comment (never emitted). Blank lines ignored.
# To add a module: append one line in [embed], insert one line in [load]
# before its first reader, rebuild. Never edit Makefile/main.c by hand.
