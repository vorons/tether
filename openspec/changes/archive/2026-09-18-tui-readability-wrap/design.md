# Design

## Context

См. `proposal.md` (Why) и `specs/tui/spec.md` (что должно получиться).
Текущее состояние в `src/tether/ui.lua`: `wrap()` режет по числу символов
(`ulen`/`usub`), ширину экрана не учитывает; рядом уже есть правильные
примитивы `char_width()` (wcwidth), `vlen()` (ширина без ANSI), `trunc()`,
которые `wrap` не использует. Код-блоки в `md_render()` не врапятся вовсе,
а обрезаются с маркером. Покрытие: `tests/lua_tests.lua` (T31/T32/T39/T40).

## Goals / Non-Goals

- Goals: один общий перенос на ширине в колонках для прозы и кода;
  ноль потерь контента при `ui.wrap = true`; без нового состояния/клавиш/конфигов.
- Non-Goals: дефисация и типографика; горизонтальный скролл; разворот
  блоков по клавише; сворачивание тул-блоков (отдельная тема).

## Decisions

1. Жадный перенос по пробелам на базе `vlen`/`char_width`.
   Разрыв только на пробеле; токен длиннее ширины без пробелов —
   жёсткий рез, как сейчас. Альтернатива — полный Unicode line-break:
   отвергнут, overkill для ленты чата.
2. Код-блоки: мягкий перенос внутри рамки с отступом продолжения,
   рамка пересчитывается под врапнутые строки. Альтернатива —
   скролл/expand по требованию: отвергнута, тянет состояние и клавиши.
3. Ветка `ui.wrap = false` не трогается (обрезка с маркером как раньше).
4. Ширина префиксов списков считается через `vlen`, а не байты
   (пуля `•` иначе едет) — часть той же правки ширины, не отдельная фича.
5. Проверки — в `tests/lua_tests.lua` рядом с T31/T32: перенос по словам,
   CJK x2, софт-врап кода без маркера, обрезка при `wrap=false`.

## Risks / Trade-offs

- [Лента станет выше на длинных строках] → принято: полнота важнее компактности (решение пользователя, вариант 1).
- [Отступ продолжения можно спутать с новой строкой кода] → Mitigation: отступ, отличный от обычного (напр. 2 пробела + визуальное отличие), зафиксировать в тестах.
- [Краевые случаи CJK/emoji/комбинирующих символов] → Mitigation: переиспользовать проверенный `char_width`, покрыть тестами.
- [Жадный перенос — не идеальная типографика] → `ponytail:` один O(n) проход без дефисов и висячих предлогов; апгрейд — нормальный line-breaker, если понадобится.

## Migration Plan

Не требуется: конфиги и сериализованные форматы не меняются, поведение
при `ui.wrap = false` прежнее. Откат — revert одного чейнджа.
