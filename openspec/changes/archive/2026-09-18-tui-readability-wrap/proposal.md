# Proposal

## Why

Обычный текст в транскрипте рвётся посреди слова, а длинные строки в код-блоках молча обрезаются с маркером `→` — хвост строки теряется и его негде посмотреть. Это два самых частых удара по читаемости TUI.

## What Changes

- Перенос прозы (ответы ассистента, пользовательские сообщения, списки) — по границам слов вместо разрыва посреди слова. Токены без пробелов длиннее ширины (URL, длинные пути) режутся жёстко, как сейчас.
- Ширина переноса считается в экранных колонках (CJK/emoji — 2 колонки, SGR-последовательности — 0), а не в символах.
- Код-блоки внутри рамки — мягкий перенос с отступом продолжения вместо обрезки с `→`. Потерь контента больше нет; рамка сохраняется.
- Поведение при `ui.wrap = false` не меняется (обрезка с `→`/`>`).

## Capabilities

### New Capabilities

— нет.

### Modified Capabilities

- `tui`: меняется требование «Markdown-lite rendering» — проза переносится по словам, код-блоки внутри рамки переносятся мягко вместо обрезки.

## Impact

- Затронут `src/tether/ui.lua` (`wrap`, `md_render`), тесты в `tests/lua_tests.lua`.
- Визуально: строки в транскрипте никогда не превышают ширину экрана, лента может стать выше на длинных строках. Нового состояния, клавиш и конфигов нет.
